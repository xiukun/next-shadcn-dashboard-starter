# 国际化（i18n）使用指南

本项目使用 [next-intl](https://next-intl-docs.vercel.app/) 实现多语言支持。

## 支持的语言

- 中文（zh）- 默认语言
- 英文（en）

## 项目结构

```
src/
├── i18n/
│   ├── config.ts          # 语言配置（支持的语言列表、默认语言）
│   ├── routing.ts         # 路由配置
│   ├── request.ts         # next-intl 请求配置
│   └── messages.ts        # 消息加载工具（合并拆分后的文件）
├── messages/
│   ├── zh/                # 中文翻译（按模块拆分）
│   │   ├── nav.json       # 导航相关
│   │   ├── common.json    # 通用文本
│   │   ├── metadata.json  # 页面元数据
│   │   ├── language.json  # 语言相关
│   │   └── settings.json # 设置相关
│   └── en/                # 英文翻译（按模块拆分）
│       ├── nav.json
│       ├── common.json
│       ├── metadata.json
│       ├── language.json
│       └── settings.json
└── app/
    └── [locale]/          # Locale 动态路由段
        ├── layout.tsx     # Locale 布局
        └── ...
```

## URL 路由格式

所有路由都包含语言前缀：

- 中文：`/zh/dashboard/overview`
- 英文：`/en/dashboard/overview`

中间件会自动检测用户语言偏好并重定向到对应的语言路由。

## 在组件中使用翻译

### 服务端组件

```typescript
import { useTranslations } from 'next-intl';

export default function Page() {
  const t = useTranslations('nav');
  return <h1>{t('dashboard')}</h1>;
}
```

### 客户端组件

```typescript
'use client';
import { useTranslations } from 'next-intl';

export function Component() {
  const t = useTranslations('common');
  return <button>{t('save')}</button>;
}
```

### 带参数的翻译

```typescript
const t = useTranslations('common');
// messages/common.json: { "welcome": "欢迎, {name}!" }
<h1>{t('welcome', { name: 'John' })}</h1>
```

## 翻译文件结构

翻译文件按命名空间组织：

- `nav`: 导航相关
- `common`: 通用文本（按钮、标签等）
- `metadata`: 页面元数据（title、description）
- `language`: 语言显示名称

### 添加新翻译

1. **按模块添加翻译**：在对应的模块文件中添加（如 `src/messages/zh/nav.json`）
2. **添加新模块**：
   - 创建新的 JSON 文件（如 `src/messages/zh/new-module.json`）
   - 在 `src/i18n/messages.ts` 中添加导入和合并逻辑
3. 在组件中使用 `useTranslations('命名空间')` 获取翻译函数
4. TypeScript 会自动提供类型检查和自动补全

### 翻译文件拆分优势

- **模块化管理**：按功能模块组织，易于维护
- **按需加载**：可以按需加载特定模块的翻译
- **团队协作**：不同开发者可以同时编辑不同模块
- **性能优化**：减少单个文件大小，提高加载速度

## 语言切换

项目提供了两种语言切换组件：

### 1. LanguageSwitcher（下拉选择器）

适用于设置面板等需要完整显示的场景：

```typescript
import { LanguageSwitcher } from '@/components/layout/language-switcher';

<LanguageSwitcher />
```

### 2. LanguageSwitcherButton（图标按钮）

适用于 Header 等需要紧凑显示的场景：

```typescript
import { LanguageSwitcherButton } from '@/components/layout/language-switcher-button';

<LanguageSwitcherButton />
```

**特性**：
- 显示当前语言
- 提供语言选择下拉菜单
- 切换语言时保持当前页面路径
- 自动更新 URL 中的 locale

**已集成位置**：
- Header 右侧（图标按钮形式）
- 设置面板 > 外观标签页（下拉选择器形式）

## 导航配置翻译

导航配置使用 `useTranslatedNavItems` hook 自动翻译：

```typescript
import { useTranslatedNavItems } from '@/hooks/use-translated-nav-items';

const translatedNavItems = useTranslatedNavItems();
```

这个 hook 会：
- 自动翻译所有导航项的标题
- 自动更新 URL 以包含 locale 前缀
- 递归处理嵌套的导航项

## 添加新语言

1. 在 `src/i18n/config.ts` 中添加新语言到 `locales` 数组：

```typescript
export const locales = ['zh', 'en', 'ja'] as const; // 添加 'ja'
```

2. 创建新的翻译目录 `src/messages/ja/` 并复制所有模块文件：
   - `nav.json`
   - `common.json`
   - `metadata.json`
   - `language.json`
   - `settings.json`
3. 翻译所有模块文件中的文本
4. 更新路由配置（如需要）

## 最佳实践

1. **命名空间组织**：按功能模块组织翻译，避免单个文件过大
2. **键名规范**：使用描述性的 camelCase 键名
3. **类型安全**：充分利用 TypeScript 类型检查
4. **渐进式迁移**：不需要一次性迁移所有文本，优先迁移用户可见的关键文本
5. **保持一致性**：所有语言文件保持相同的结构

- `src/components/layout/language-switcher-button.tsx` - 语言切换组件（图标按钮）
