# Header 设置面板规范

## 目的

提供统一的 Header 设置面板，允许用户自定义导航显示方式（标签栏/面包屑）和主题设置，提升用户体验和界面可定制性。

## 新增需求

### 需求：用户偏好设置存储

系统**必须**提供用户偏好设置的持久化存储机制，**必须**使用 Zustand + persist 实现，**必须**支持 SSR 兼容。

#### 场景：初始化用户偏好设置

- **当** 用户首次访问应用时
- **那么** 使用默认值初始化偏好设置
- **并且** 默认启用标签栏（`enableTabs: true`）
- **并且** 默认显示面包屑（`showBreadcrumbs: true`）
- **并且** 默认面包屑样式为常规（`breadcrumbStyle: 'regular'`）

#### 场景：持久化用户偏好设置

- **当** 用户修改任何偏好设置时
- **那么** 立即保存到 localStorage
- **并且** 下次访问时自动恢复设置
- **并且** 使用 `skipHydration: true` 避免 SSR 不匹配

#### 场景：更新标签栏设置

- **当** 用户在设置面板中切换"启用标签栏"开关时
- **那么** 立即更新 `enableTabs` 状态
- **并且** Header 中的导航组件立即响应变化
- **并且** 设置自动保存到 localStorage

#### 场景：更新面包屑设置

- **当** 用户在设置面板中切换"显示面包屑"开关时
- **那么** 立即更新 `showBreadcrumbs` 状态
- **并且** 当标签栏关闭时，面包屑显示/隐藏立即响应
- **并且** 设置自动保存到 localStorage

#### 场景：更新面包屑样式

- **当** 用户在设置面板中选择面包屑样式时
- **那么** 立即更新 `breadcrumbStyle` 状态
- **并且** Breadcrumbs 组件立即应用新样式
- **并且** 设置自动保存到 localStorage

### 需求：Header 设置面板

系统**必须**在 Header 组件中提供设置入口，**必须**以对话框或抽屉形式显示设置面板，**必须**包含布局和外观两个标签页。

#### 场景：打开设置面板

- **当** 用户点击 Header 右侧的设置按钮（齿轮图标）时
- **那么** 打开设置面板对话框/抽屉
- **并且** 显示"布局"和"外观"两个标签页
- **并且** 默认显示"布局"标签页

#### 场景：关闭设置面板

- **当** 用户点击设置面板的关闭按钮或遮罩层时
- **那么** 关闭设置面板
- **并且** 保持所有设置更改（已自动保存）

#### 场景：布局标签页内容

- **当** 用户打开设置面板并切换到"布局"标签页时
- **那么** 显示"启用标签栏"开关
- **并且** 显示"显示面包屑"开关（当标签栏开启时禁用）
- **并且** 显示"面包屑样式"选择器（常规/背景）
- **并且** 所有设置实时生效

#### 场景：外观标签页内容

- **当** 用户打开设置面板并切换到"外观"标签页时
- **那么** 显示主题选择器（原 ThemeSelector 组件）
- **并且** 显示主题模式切换（原 ThemeModeToggle 组件）
- **并且** 所有设置实时生效

### 需求：Header 条件渲染导航组件

系统**必须**根据用户偏好设置条件渲染导航组件，**必须**在标签栏和面包屑之间切换，**必须**确保切换平滑无闪烁。

#### 场景：显示标签栏

- **当** `enableTabs` 为 `true` 时
- **那么** Header 中显示 `RouteTabs` 组件
- **并且** 隐藏 `Breadcrumbs` 组件
- **并且** RouteTabs 组件正常渲染所有功能

#### 场景：显示面包屑

- **当** `enableTabs` 为 `false` 且 `showBreadcrumbs` 为 `true` 时
- **那么** Header 中显示 `Breadcrumbs` 组件
- **并且** 隐藏 `RouteTabs` 组件
- **并且** Breadcrumbs 组件根据 `breadcrumbStyle` 应用样式

#### 场景：隐藏所有导航组件

- **当** `enableTabs` 为 `false` 且 `showBreadcrumbs` 为 `false` 时
- **那么** Header 中不显示任何导航组件
- **并且** 仅显示 SidebarTrigger 和右侧操作按钮

### 需求：Header 右侧按钮区域调整

系统**必须**从 Header 右侧移除主题相关按钮，**必须**将主题设置集成到设置面板中。

#### 场景：移除主题按钮

- **当** Header 组件渲染时
- **那么** 不显示 `ThemeSelector` 组件
- **并且** 不显示 `ThemeModeToggle` 组件
- **并且** 右侧按钮区域仅显示：搜索框、用户导航、设置按钮

#### 场景：添加设置按钮

- **当** Header 组件渲染时
- **那么** 在右侧按钮区域显示设置按钮（齿轮图标）
- **并且** 点击设置按钮打开设置面板
- **并且** 设置按钮使用合适的图标和样式

## 修改需求

### 需求：RouteTabs 组件响应偏好设置

系统**必须**修改 RouteTabs 组件，使其能够响应 `enableTabs` 设置，**必须**在设置关闭时不渲染。

#### 场景：标签栏启用时渲染

- **当** `enableTabs` 为 `true` 时
- **那么** RouteTabs 组件正常渲染
- **并且** 所有标签页功能正常工作

#### 场景：标签栏关闭时不渲染

- **当** `enableTabs` 为 `false` 时
- **那么** RouteTabs 组件返回 `null`
- **并且** 不执行任何渲染逻辑

### 需求：Breadcrumbs 组件响应偏好设置

系统**必须**修改 Breadcrumbs 组件，使其能够响应 `enableTabs` 和 `showBreadcrumbs` 设置，**必须**支持不同的面包屑样式。

#### 场景：面包屑显示时渲染

- **当** `enableTabs` 为 `false` 且 `showBreadcrumbs` 为 `true` 时
- **那么** Breadcrumbs 组件正常渲染
- **并且** 根据 `breadcrumbStyle` 应用相应样式类

#### 场景：面包屑隐藏时不渲染

- **当** `enableTabs` 为 `true` 或 `showBreadcrumbs` 为 `false` 时
- **那么** Breadcrumbs 组件返回 `null`
- **并且** 不执行任何渲染逻辑

#### 场景：应用面包屑样式

- **当** `breadcrumbStyle` 为 `'regular'` 时
- **那么** Breadcrumbs 组件应用常规样式（无背景）
- **当** `breadcrumbStyle` 为 `'background'` 时
- **那么** Breadcrumbs 组件应用背景样式（有背景色）

## 实现约束

1. **状态管理**：使用 Zustand 创建 `useUserPreferencesStore`，使用 `persist` 中间件持久化
2. **SSR 兼容**：使用 `skipHydration: true` 避免服务端和客户端状态不匹配
3. **实时更新**：所有设置更改立即生效，无需点击保存按钮
4. **默认值**：首次访问时使用提案中定义的默认值
5. **组件复用**：ThemeSelector 和 ThemeModeToggle 组件移动到设置面板中复用，不修改其内部逻辑
6. **类型安全**：所有新增接口和函数必须提供完整的 TypeScript 类型定义
7. **可访问性**：设置面板必须支持键盘导航和屏幕阅读器
