# layout 规范 - 全屏和刷新功能增量

## 新增需求

### 需求：全屏功能

系统**必须**提供全屏功能，**必须**允许用户将内容区域切换为全屏模式，**必须**在全屏模式下隐藏侧边栏和 Header，**必须**支持通过按钮和浏览器快捷键切换全屏状态。

#### 场景：点击全屏按钮进入全屏

- **当** 用户点击 Header 右侧的全屏按钮时
- **那么** 系统调用浏览器 Fullscreen API 进入全屏模式
- **并且** 侧边栏被隐藏
- **并且** Header 保持显示
- **并且** 内容区域占满剩余屏幕空间（Header 下方）
- **并且** 全屏按钮图标切换为退出全屏图标
- **并且** 全屏状态同步到 Store

#### 场景：点击退出全屏按钮退出全屏

- **当** 用户在全屏模式下点击退出全屏按钮时
- **那么** 系统调用浏览器 Fullscreen API 退出全屏模式
- **并且** 侧边栏重新显示
- **并且** Header 保持显示
- **并且** 内容区域恢复为正常布局
- **并且** 退出全屏按钮图标切换为全屏图标
- **并且** 全屏状态同步到 Store

#### 场景：浏览器原生全屏快捷键同步状态

- **当** 用户使用浏览器原生全屏快捷键（F11）进入或退出全屏时
- **那么** 系统监听 `fullscreenchange` 事件
- **并且** 自动同步全屏状态到 Store
- **并且** Header 中的全屏按钮图标自动更新
- **并且** 布局自动调整（显示/隐藏侧边栏，Header 始终显示）

#### 场景：全屏状态持久化（可选）

- **当** 用户进入全屏模式后刷新页面时
- **那么** 系统不保留全屏状态（全屏状态不持久化）
- **并且** 页面以正常布局加载

### 需求：标签页刷新功能

系统**必须**在激活的标签页上提供刷新按钮，**必须**允许用户刷新当前标签页的内容，**必须**仅在激活的标签页上显示刷新按钮。

#### 场景：显示刷新按钮

- **当** 标签页处于激活状态时
- **那么** 在该标签页上显示刷新按钮
- **并且** 刷新按钮位于标签页标题右侧
- **并且** 刷新按钮使用刷新图标

#### 场景：隐藏刷新按钮

- **当** 标签页处于非激活状态时
- **那么** 在该标签页上不显示刷新按钮
- **并且** 只有激活的标签页显示刷新按钮

#### 场景：点击刷新按钮刷新页面

- **当** 用户点击激活标签页上的刷新按钮时
- **那么** 系统刷新当前标签页对应的路由
- **并且** 使用 Next.js 的 `router.refresh()` 或 `window.location.reload()` 刷新页面
- **并且** 刷新后标签页保持激活状态
- **并且** 刷新按钮不影响标签页的点击和关闭功能

#### 场景：刷新按钮交互

- **当** 用户将鼠标悬停在刷新按钮上时
- **那么** 刷新按钮显示 hover 效果
- **并且** 刷新按钮可以独立点击，不影响标签页的点击
- **当** 用户点击刷新按钮时
- **那么** 触发刷新操作，不触发标签页切换

### 需求：图标扩展

系统**必须**在图标库中添加全屏和刷新相关的图标，**必须**支持全屏和退出全屏两种状态的图标显示。

#### 场景：添加全屏图标

- **当** 系统需要显示全屏按钮时
- **那么** 使用 `Icons.fullscreen` 图标（对应 `IconMaximize` 或 `IconArrowsMaximize`）
- **并且** 图标正确显示在 Header 右侧按钮区域

#### 场景：添加退出全屏图标

- **当** 系统处于全屏模式需要显示退出全屏按钮时
- **那么** 使用 `Icons.fullscreenExit` 图标（对应 `IconMinimize` 或 `IconArrowsMinimize`）
- **并且** 图标正确显示在 Header 右侧按钮区域

#### 场景：添加刷新图标

- **当** 系统需要在标签页上显示刷新按钮时
- **那么** 使用 `Icons.refresh` 图标（对应 `IconRefresh` 或 `IconRefreshDot`）
- **并且** 图标正确显示在激活标签页的标题右侧
