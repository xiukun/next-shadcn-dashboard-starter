# 变更提案：优化侧边栏折叠行为

**变更 ID**: `20260217155832-optimize-sidebar-collapse-behavior`  
**创建时间**: 2026-02-17  
**状态**: 已完成

## 变更概述

优化左侧菜单在折叠状态下的显示效果，并在设置面板中增加折叠效果选择功能，允许用户选择两种不同的折叠模式。

## 为什么

### 问题背景

1. **折叠状态体验不一致**：当前侧边栏折叠时，子菜单项会被完全隐藏，用户需要先展开侧边栏才能看到子菜单，交互不够直观
2. **缺乏个性化选择**：不同用户对折叠状态下的菜单显示方式有不同的偏好需求
3. **多级菜单展示需求**：部分用户希望在折叠状态下也能看到多级菜单的所有子项，提升导航效率

### 解决方案

通过添加折叠效果选择功能，提供两种折叠模式：
- **模式1（图标模式）**：折叠时只显示图标，点击图标后展开多级菜单（当前默认行为）
- **模式2（展开子项模式）**：折叠时只显示图标，鼠标悬停在有子菜单的图标上时，通过 HoverCard 弹框显示所有子菜单项，点击不会展开侧边栏

## 变更原因

1. **用户体验优化**：提供更灵活的折叠菜单展示方式，满足不同用户的使用习惯
2. **导航效率提升**：模式2允许用户在侧边栏折叠状态下直接访问所有子菜单项，减少操作步骤
3. **个性化定制**：通过设置面板提供选择，让用户根据个人偏好自定义侧边栏行为

## 变更内容

### 1. 扩展用户偏好设置 Store

- **文件**: `src/lib/user-preferences-store.ts`
- **新增字段**:
  - `sidebarCollapseMode`: `'icon' | 'expanded-submenu'`
    - `'icon'`: 图标模式（默认），折叠时只显示图标，点击展开子菜单
    - `'expanded-submenu'`: 展开子项模式，折叠时只显示图标，鼠标悬停时通过 HoverCard 显示子菜单项

### 2. 修改导航主组件（使用 HoverCard）

- **文件**: `src/components/layout/app-sidebar.tsx`
- **修改内容**:
  - 引入 `HoverCard` 组件用于悬停显示子菜单
  - 在 `'expanded-submenu'` 模式且折叠状态下，使用 `HoverCard` 包裹有子菜单的菜单项
  - 子菜单默认隐藏，只在鼠标悬停时通过 `HoverCardContent` 显示
  - 点击菜单项不会展开侧边栏

### 3. 修改导航主组件逻辑

- **文件**: `src/components/layout/app-sidebar.tsx`
- **修改内容**:
  - 读取 `sidebarCollapseMode` 设置和侧边栏状态
  - 根据模式调整子菜单的显示逻辑
  - 在 `'expanded-submenu'` 模式且折叠状态下，子菜单默认隐藏，通过悬停显示
  - 使用 `useSidebar` hook 获取侧边栏状态

### 4. 扩展设置面板

- **文件**: `src/components/layout/settings-panel.tsx`
- **新增内容**:
  - 在"布局"标签页中新增"侧边栏折叠效果"设置项
  - 使用 RadioGroup 提供两个选项：
    - "图标模式"：折叠时只显示图标，点击展开子菜单
    - "展开子项模式"：折叠时只显示图标，鼠标悬停显示子菜单

## 技术考虑

### 实现方式

1. **状态管理**：使用现有的 `useUserPreferencesStore` 扩展状态
2. **样式控制**：通过 CSS 类和条件渲染控制子菜单显示
3. **响应式设计**：确保两种模式在移动端和桌面端都能正常工作

### 潜在风险

1. **性能影响**：展开子项模式可能增加渲染的 DOM 节点数量，需要验证性能
2. **样式冲突**：折叠状态下的子菜单样式可能需要特殊处理
3. **交互体验**：展开子项模式下的交互逻辑需要仔细设计，避免与展开/折叠操作冲突
